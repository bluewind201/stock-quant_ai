    4. 보유와 매도당일 마감으로 팔지 않습니다. 보호 가격이나 추세가 깨지거나 투자 근거가 훼손되면 정리합니다. 장기 방식은 가격 추세 전략이며 기업 가치평가를 대신하지 않습니다.

    컨테이너 콘솔을 쓴다면 사용자 ID를 10001로 선택하고 CODEX_HOME=/home/stock/.stock-codex codex -c 'cli_auth_credentials_store="file"' login --device-auth를 실행하세요. root 사용자로 인증하면 앱 사용자가 읽지 못할 수 있습니다. 표시되는 주소를 PC에서 열어 코드를 입력합니다. ChatGPT 보안 설정에서 기기 코드 로그인을 허용해야 할 수 있습니다.

    로그인 후 연결 확인을 누르세요. 인증 파일은 Compose의 Codex 볼륨에 보관됩니다.
