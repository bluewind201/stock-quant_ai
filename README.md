## 하루 흐름 (KST, 전부 설정으로 바꿀 수 있음)

국내 장은 **08:00~20:00** 입니다 — 프리마켓(NXT) 08:00~09:00 · 정규장 09:00~15:30 · 애프터마켓(NXT) 15:30~20:00.
매일 토스 캘린더에서 실제 시간을 받아 쓰고, **그 밖에서는 매수·매도·판단을 일절 하지 않습니다.**
기본 시간표는 정규장 기준이며, 설정에서 프리마켓·애프터마켓 프리셋으로 한 번에 바꿀 수 있습니다.

| 시각 | 주체 | 하는 일 |
|---|---|---|
| 07:30 | 프로그램 | 테마 상위 20 ∪ 거래대금 상위 50 ∪ 상승률 상위 50 → 거래대금·급등·투자경고로 거르고 수급·기사를 붙여 후보 15종 |
| 이어서 | **AI** | **오늘 살지 말지**부터 정하고, 산다면 종목·비중·익절 %·손절 %. 실패하면 3분 뒤 재시도 |
| 09:00 | 프로그램 | 매수 + 익절·손절 괄호 |
| 장중 | 프로그램 | 괄호 감시(손절 우선). 급등·새 기사 때만 AI 에게 다시 묻는다 |
| 15:00 | **AI** | 남은 보유분 "내일까지 갈 것 같은가" + **오늘 크게 눌린 종목을 내일 반등 보고 살까** |
| 15:20 | 프로그램 | 익일 보유 판정 외 전부 정리 → 텔레그램 마감 요약 |
| 정리 직후 | **AI** | **마감 복기** — 왜 됐는지/안 됐는지, 내일 바꿀 숫자와 교훈 (자동 반영) |

오전에 "오늘은 안 산다"고 판단하는 것은 정상이고 자주 옳습니다. 그런 날도 마감에 다시 봅니다.
장전·마감·복기 판단은 하루 AI 호출 한도와 무관하게 항상 실행되고, 각 단계를 **실제로 몇 시에 했는지** 대시보드에 남습니다.

자세한 규칙과 AI 가 보는 데이터는 [DAYTRADE.md](DAYTRADE.md).

## AI 가 보는 것

- 후보 종목별: 전일 등락·거래대금, 외국인·기관·개인 순매수(1일·3일), 소속 테마와 테마 등락, **최근 24시간 기사 제목+본문 요약** (네이버)
- 국내 시장 전체: 코스피·금리·정책·해외 요인 **기사 제목 15건** (구글 뉴스, 3.4.0 부터)
- 미국 거시: 연준·백악관·경제기관 발표 **제목 30건**, 경제 일정 (마감 판단 때 "오늘 밤 큰 발표면 들고 가지 말라")
- **간밤 미국을 숫자로**: 한국장이 닫힌 동안 거래된 미국 ETF 등락률 — EWY(MSCI 한국 ETF)·SOXX(반도체)·QQQ·SPY·XLE·TLT.
  EWY 는 간밤 외국인이 한국을 어떻게 값매겼는지 그대로 보여줍니다
- **최근 3거래일 내 선택과 결과**: 같은 테마를 관성으로 반복하지 않도록

무엇을 봤는지는 대시보드 "오늘 AI가 본 자료" 와 뉴스 탭에 그대로 남습니다.

## 시작하기

1. NAS 에 `docker-compose.yml` 과 `.env` 를 올리고 `docker compose up -d` — [SYNOLOGY.md](SYNOLOGY.md)
2. `.env` 에 `ADMIN_PASSWORD`, 토스 키, `CLAUDE_CODE_OAUTH_TOKEN`(PC 에서 `claude setup-token`), 텔레그램 봇 토큰·chat id — [.env.example](.env.example)
3. 화면 **설정 · 연결** 에서 세 가지 연결 확인
4. **당일 단타 → 모의 운용** 에서 계좌 만들기 (기본값 그대로 가능) → **운용 시작**
5. 다음 거래일 07:30 부터 자동. 결과는 대시보드와 텔레그램으로
6. 며칠 모의 실적이 납득되면 `.env` 에 `ENABLE_LIVE_TRADING=true`, `TOSS_ACCOUNT_SEQ`, `LIVE_CAPITAL_KRW` 를 넣고 컨테이너 재생성 → **당일 단타 → 실거래** 에서 계좌 만들기 → "실거래 시작" 입력. 자세한 규칙과 한계는 [DAYTRADE.md](DAYTRADE.md)

로컬 검증(Windows)은 `.venv-stock` 에서 `python -m uvicorn sqt.api:app --app-dir core --port 8430`. 테스트는 `python -m pytest core/tests -q`.
