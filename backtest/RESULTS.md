# 진입 게이트 백테스트 — 2026-09-10

## 무엇을 측정했나

실제로 거래하는 경로는 **GPT 제안 → `decision_quality.buy_reasons()` 판정**입니다.
GPT는 4년치를 재생할 수 없지만 GPT는 *제안만* 하고 결정은 코드가 합니다.
그래서 GPT 자리에 "매일 모든 종목에 스윙 진입을 제안하는 생성기"를 넣고,
**실제 게이트 코드**가 고르게 했습니다. 통과한 것이 곧 배포된 코드가 허용했을 진입입니다.

| 실험군 | 내용 |
|---|---|
| **게이트** | `buy_reasons()` 가 아무 사유도 반환하지 않은 날에만 진입 |
| **무작위** | 같은 건수를 전체 후보일에서 균등 추출 (귀무가설) |
| **보유만** | 게이트와 **같은 날짜**에 진입하되 손절·익절을 끄고 보유 |

"보유만"이 있어야 *게이트가 날짜를 잘 골랐는가* 와 *손절·익절 구조가 일했는가* 를 분리할 수 있습니다.

## 데이터

- 국내 25종 + 미국 25종, **일봉 1000봉씩 = 약 4년** (2022-08-05 ~ 2026-09-09)
- 출처: 토스증권 Open API `/api/v1/candles` (1000봉이 API 상한)
- 총 5만 개 일봉, 게이트 평가 21,518건
- 비용 반영: 수수료 10bp · 슬리피지 10bp · 스프레드 10bp · 국내 매도 거래세 15bp
- 선견편향 차단: **전일까지의 완료 봉으로 판단 → 당일 시가에 체결**. 갭은 시가로 체결하고,
  같은 봉에서 손절·익절이 함께 닿으면 손절을 우선 적용(보수적)

## 결론

### 1. 게이트에 우위가 없습니다

다섯 설정 모두에서 게이트는 무작위 진입 분포의 **45~49 백분위**에 있습니다.
즉 정확히 한가운데이며, 우위가 확인된 설정이 하나도 없습니다.
95% 신뢰구간을 벗어난 경우도 없습니다.

게이트가 막는 사유는 사실상 두 개뿐입니다.

```
14,754회  일봉 중기 추세 아래        (SMA60 미만)
 4,376회  일봉 평균 대비 과도한 이격  (SMA20 + ATR×2 초과)
    92회  비용 반영 목표 손익비 부족
```

"상승 추세이고 너무 과열되지 않은 종목"을 고르는 것인데, **그 조건이 이후 수익률을
무작위보다 낫게 만들지 못합니다.**

비용 게이트(`min_reward_risk=1.5`)는 21,518건 중 **92건(0.4%)** 만 막았습니다.
ATR 기반 손절에 2R 목표를 쓰면 비용 차감 후에도 손익비가 거의 항상 1.5를 넘기 때문에
사실상 작동하지 않는 조건입니다.

### 2. 손절·익절 구조가 수익을 깎고 있습니다 — 이게 더 큰 문제입니다

**같은 날 진입했는데** 손절·익절을 끄면 모든 설정에서 성적이 좋아집니다.

```
ATR×1.5 / 20일 :  게이트 +0.129%  →  보유만 +1.695%   (승률 39.8% → 51.7%)
ATR×2.5 / 40일 :  게이트 +1.432%  →  보유만 +3.856%   (승률 45.4% → 56.9%)
ATR×3.5 / 40일 :  게이트 +2.106%  →  보유만 +3.870%   (승률 50.1% → 56.1%)
```

손절이 추세가 전개되기 전에 잡음에 먼저 걸립니다. 손절폭을 넓히면 격차가 줄지만
**어느 설정에서도 역전되지 않습니다.**

### 3. 규모 감각

게이트는 4년간 2,296회 거래해서 회당 평균 +0.129%를 냈습니다.
같은 기간 같은 종목을 그냥 들고 있으면 중앙값 +97.3%였습니다.

## 이 백테스트가 답하지 못하는 것

- **단타(scalp) 설정** — 토스는 최근 100분봉만 줍니다. 장중 전략은 과거 데이터가
  없어 모의 운용으로만 검증됩니다. 위 결과는 스윙 경로에만 해당합니다.
- **뉴스·거시 게이트** — `news.py` 는 현재 RSS를 읽습니다. 시점 복원이 불가능해
  백테스트는 뉴스 없이 돌았고, 실거래는 그렇지 않습니다.
- **GPT의 기여** — 과거 데이터로는 알 수 없습니다. 다만 위 결과가
  **GPT가 넘어야 할 기준선**입니다. GPT가 종목·시점을 골라서 무작위보다 나아야
  이 시스템이 의미를 갖습니다.

## 알면서 남긴 편향

- **생존 편향** — 지금 상장된 종목만 조회됩니다. 상장폐지·합병된 종목이 빠져
  모든 실험군이 실제보다 좋게 나옵니다.
- **강세장 구간** — 4년 내내 상승장이었습니다. "보유만"이 유리한 것은 당연하고,
  하락장에서는 손절이 방어할 수 있습니다. 다만 그 경우에도 *게이트의 종목 선택*이
  무작위와 같다는 결론은 바뀌지 않습니다.
- **재진입 쿨다운 무효** — `reentry_cooldown_minutes` 는 분 단위 규칙이라
  일봉 백테스트에서는 한 번도 발동하지 않았습니다.
